# رحمة للمستلزمات الطبية - لوحة التحكم (Frontend)

لوحة التحكم الخاصة بنظام الربط والمزامنة بين منصة زد ونظام دفترة لمؤسسة رحمة للمستلزمات الطبية.

## المتطلبات والتشغيل المحلي

1. تثبيت الحزم:
```bash
npm install
```

2. التشغيل في بيئة التطوير:
```bash
npm run dev
```

3. بناء الإنتاج:
```bash
npm run build
```
